# 外部記憶（External Memory）と個体固有状態（Individual State）の境界

[英語版（正本）](external-memory-boundary.md)

**状態（Status）:** 概念（Concept）— M0 作業定義  
**関連Issue:** #8

## 定義

ASAにおける**外部記憶（External Memory）**とは、個体（Individual）の内部状態から独立して保持され、個体の交換・退役・再生成をまたいで参照可能な情報資産である。ただし、保存場所が外部であることだけでは共有知識とはみなさない。

重要な境界は物理的な保存場所ではなく、**情報の帰属・共有範囲・検証責任**である。

個体の状態をディスクやデータベースに保存していても、それが当該個体だけに帰属し、後継や他個体へ自動共有されないなら、意味上は個体固有状態（Individual State）である。

## 情報の4層

ASAでは情報を少なくとも次の4層に分ける。

1. **一時実行状態（Transient Runtime State）**  
   現在の推論、短期文脈、中間計算、未確定仮説など。原則として個体の現在実行にのみ必要。

2. **個体固有永続状態（Persistent Individual State）**  
   個体の作業継続、責任履歴、限定的な個体記憶のために永続化されるが、社会共有資産ではない情報。

3. **共有知識・技能（Shared Knowledge and Skills）**  
   検証を経て、複数個体や次世代が利用できる知識、技能、手順、モデル化された経験。

4. **制度・監査記録（Institutional and Audit Records）**  
   規則、権限履歴、状態遷移、監査証跡、判断根拠など、個体を超えて社会の継続性と検証可能性を支える記録。

## 配置原則

| 情報種別 | 帰属 | 原則的な保存先 | 個体退役後 |
| --- | --- | --- | --- |
| 推論途中の思考状態 | 個体 | 一時状態 | 原則破棄 |
| 現在タスクの作業文脈 | 個体 | 個体固有永続状態 | 必要部分のみ引継ぎ |
| 個体固有の未検証仮説 | 個体 | 個体固有永続状態 | 原則共有しない |
| 検証済み事実 | 社会 | 共有知識 | 継続利用可能 |
| 技能・手順 | 社会 | 共有知識 / 能力（Capability） | 継続利用可能 |
| 失敗事例・教訓 | 条件付き社会 | 検証後に共有知識 | 検証済み部分のみ残す |
| 権限付与・失効履歴 | 制度 | 監査記録 | 永続保存 |
| 個体の重要判断と行動 | 制度 | 監査記録 | 永続保存 |
| 社会規則・憲法的制約 | 制度 | 制度記録 | 個体から独立して維持 |

## 個体交換時の状態移送

個体Aから後継個体Bへ移行する際、Aの内部状態全体を複製してはならない。移送対象は、**後継が責務を継続するために必要な最小限の引継ぎパッケージ（Handover Package）**に限定する。

引継ぎパッケージには、例えば次を含める。

- 未完了タスクと現在状態
- 既知の前提条件
- 未解決の不確実性
- 参照すべき共有知識
- 重要な直近判断と根拠
- 必要な監査参照

一方、個体固有の未検証推測、長大な会話履歴、内部推論の全記録、個人的な傾向などは原則として自動移送しない。

## 共有知識への昇格

個体の経験は、そのまま社会の知識にならない。

```text
個体の観測・経験
    ↓
知識候補（Candidate Knowledge）
    ↓
出典確認
    ↓
再現・反証可能性確認
    ↓
他個体または独立系による検証
    ↓
共有知識（Shared Knowledge）
```

共有知識には少なくとも次のメタデータを持たせる。

- 出典（Provenance）
- 検証状態（Validation Status）
- 鮮度（Freshness）
- 適用条件（Applicability）
- 反証履歴（Refutation History）
- 生成元個体または生成経路

## 失敗ケース: 誤情報の社会化

個体Aが誤った仮説Xを持ち、それを検証なしに共有知識へ書き込んだとする。

その後、個体B・C・DがXを共有知識として参照すると、単一個体の誤りが社会全体の共通前提へ変化する。

```text
Individual A error
      ↓
Unvalidated write
      ↓
Shared Memory
   ↓   ↓   ↓
  B    C    D
      ↓
Common-mode failure
```

これは個体の誤りより危険な場合がある。そのため、**共有記憶への書き込み権限は、個体の通常実行権限とは分離し、検証経路を必須とする。**

## 外部記憶の重要原則

1. **外部記憶は保存場所ではなく、個体から独立した情報資産として定義する。**
2. **永続化された個体状態と共有知識を混同しない。**
3. **個体交換時は内部状態全体ではなく、必要最小限の引継ぎ情報だけを移送する。**
4. **個体の経験は検証なしに共有知識へ昇格しない。**
5. **共有知識は出典・検証状態・鮮度・反証履歴を持つ。**
6. **監査記録と制度記録は、個体や世代から独立して保持する。**

# 個体（Individual）

[英語版（正本）](individual.md)

**状態（Status）:** 概念（Concept）— M0 作業定義  
**関連Issue:** #6

## 定義

ASAにおける**個体（Individual）**とは、固有の個体識別（Identity）、生成起点（Genesis）、有限の寿命（Lifetime）、境界付けられた権限（Authority）、認知特性（Cognitive Profile）、および監査可能な状態履歴（Audit Lineage）を持ち、その存続期間中の判断と行動について一つの責任単位として扱われる自律知性である。

個体は、モデル、実行プロセス、仮想マシン、セッション、ハードウェアそのものとは同一ではない。これらは個体を実装または実行する構成要素になり得るが、個体の継続性は、個体識別、権限、寿命、状態履歴の連続性によって判断する。

## 最小構成

個体は少なくとも次を定義する。

- **個体識別（Identity）** — 一意な個体識別子と系譜・世代参照。
- **生成起点（Genesis）** — 個体が生成されたときの構成と条件。
- **寿命（Lifetime）** — 生成時刻、失効条件、ライフサイクル状態。
- **権限（Authority）** — 許可された能力、制限、権限失効条件。
- **認知特性（Cognitive Profile）** — 評価済み行動に影響するモデルその他の特性。
- **個体固有状態（Individual State）** — 共有知識とは扱わない一時的または私的な状態。
- **外部参照（External References）** — 共有知識、技能、手順、制度上の規則への参照。
- **監査履歴（Audit Lineage）** — 重要な判断、行動、状態遷移を再構成できる履歴。

## 個体の継続性

実行実体（Runtime）の再起動だけでは、新しい個体は生成されない。次の要素が継続し、検証可能であれば、プロセス再起動、ホスト移行、ハードウェア交換などをまたいでも同一個体として扱える。

- 個体識別
- 生成起点と系譜
- 寿命とライフサイクル状態
- 権限契約
- 正当な状態の連続性
- 監査履歴

## 新しい個体を必要とする変更

現在個体が評価された特性を実質的に超える変更を行う場合は、新しい個体を生成する。

代表例は、認知モデル、推論アーキテクチャ、行動方針など、判断特性を大きく変える変更である。

原則として次を置く。

> **重要な認知特性の変更は、新しい個体を生成する。**

軽微な適応は、明示的に認められた**許容適応範囲（Allowed Adaptation Envelope）**の中にある場合に限り、同一個体の生涯内学習（Lifetime Learning）として扱える。この範囲の定義方法は後続研究課題とする。

## 判定例

| ケース | 同一個体か | 理由 |
| --- | --- | --- |
| プロセスが障害停止し、正当な状態から再起動 | はい | 実行実体だけが変化し、責任履歴は継続するため。 |
| ハードウェア障害後に別マシンへ移行 | はい | ハードウェアは個体識別を定義しないため。 |
| 文脈を圧縮して検証済み状態として復元 | 原則はい | 状態表現は変わるが責任単位は継続するため。 |
| 基盤言語モデルを実質的に異なるモデルへ交換 | 原則いいえ | 評価済み判断特性が維持される保証がないため。 |
| 意味・行動特性を変えない指示文の表現修正 | 条件付きで同一 | 許容適応範囲内であることが必要。 |
| 完全コピーした個体を並行して起動 | いいえ | 独立した判断履歴を持ち始めるため、別の個体識別が必要。 |
| 障害復旧として単一のチェックポイントから再開 | 同一になり得る | 並行分岐ではなく、一つの監査可能な履歴として継続できるため。 |

## 曖昧なケース: オンライン学習

継続的な学習では、どの時点から別個体とみなすかが問題になる。ASAではパラメータの一致・不一致だけで個体性を定義しない。

代わりに、適応がその個体について事前に受容された行動・保証範囲内にあるかで判断する。

その範囲を超える変更は、稼働中個体の自己変更ではなく、後継候補（Successor Candidate）として扱う。

## 設計上の帰結

1. **個体は実行単位ではなく責任単位である。**
2. **並行して存在するコピーは別個体である。**
3. **重要な認知特性の変更は、後継候補の出生として扱う。**
4. **実行復旧と世代交代は別の操作である。**

## 未解決事項

最大の未解決事項は、モデルや実装に依存せずに許容適応範囲（Allowed Adaptation Envelope）をどのように定義・測定するかである。
